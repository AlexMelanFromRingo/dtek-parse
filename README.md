# DTEK Power Outage Schedule Parser

Парсер для автоматичного отримання графіків відключень електроенергії ДТЕК. Парсер витягує інформацію безпосередньо з HTML сторінки, дозволяючи швидко отримувати актуальні дані про відключення без ручного введення адреси на сайті.

## 🚀 Можливості

- ✅ Автоматичне завантаження HTML з сайту ДТЕК
- ✅ Парсинг JavaScript даних (`DisconSchedule.streets`, `DisconSchedule.fact`)
- ✅ Пошук групи відключень (GPV) для конкретної адреси через AJAX
- ✅ Отримання графіків відключень на кілька днів вперед
- ✅ Розшифровка статусів (є світло, відключення, можливе відключення)
- ✅ Виведення даних в зручному читабельному форматі
- ✅ Підтримка експорту в JSON

```bash
# Клонуйте репозиторій або скопіюйте файли
git clone <your-repo>
cd dtek-parse

# Встановіть залежності
pip install -r requirements.txt
```

### ⚠️ Важливо: Сайт захищений Incapsula

Сайт ДТЕК використовує **Incapsula** (Imperva) антибот захист. Для роботи парсера **обов'язково** потрібно встановити `cloudscraper`:

```bash
pip install cloudscraper
```

Без `cloudscraper` парсер не зможе завантажити дані, оскільки звичайні HTTP запити блокуються.

## 📖 Використання

### Базове використання

```bash
python dtek_parser.py "м. Дніпро" "вул. Конотопська" "169"
```

### Режим діагностики (рекомендовано при проблемах)

```bash
python dtek_parser.py "м. Дніпро" "вул. Конотопська" "169" --debug
```

### Перегляд доступних міст

```bash
# Всі міста
python dtek_parser.py --list-cities

# Фільтр по назві
python dtek_parser.py --list-cities --filter "Дніпро"
```

### Збереження HTML для діагностики

```bash
python dtek_parser.py "м. Дніпро" "вул. Конотопська" "169" --save-html page.html --debug
```

### Вивід JSON

```bash
python dtek_parser.py "м. Дніпро" "вул. Конотопська" "169" --json
```

### Програмне використання

```python
from dtek_parser import DTEKParser

# Створюємо парсер
parser = DTEKParser()

# Отримуємо інформацію про відключення
info = parser.get_outage_info(
    city="м. Дніпро",
    street="вул. Конотопська",
    house_num="169"
)

# Виводимо результат
parser.print_schedule(info)

# Або працюємо з даними безпосередньо
if info['success']:
    print(f"Група: {info['group']}")
    print(f"Оновлено: {info['update_time']}")

    for date, schedule in info['schedules'].items():
        print(f"\n{date}")
        for time_range, status in schedule:
            print(f"{time_range}: {status}")
```

## 📊 Формат відповіді

Парсер повертає словник з наступною структурою:

```python
{
    'success': True,
    'address': 'м. Дніпро, вул. Конотопська, 169',
    'group': 'GPV1.1',  # Група відключень
    'group_name': 'Черга 1.1',  # Назва групи
    'update_time': '18.12.2025 20:00',  # Час останнього оновлення
    'schedules': {
        '2025-12-18 (Wednesday)': [
            ('00:00-01:00', '✅ Є СВІТЛО'),
            ('01:00-02:00', '✅ Є СВІТЛО'),
            ('02:00-03:00', '❌ ВІДКЛЮЧЕННЯ'),
            # ... решта годин
        ],
        # ... інші дні
    }
}
```

## 🔍 Статуси відключень

| Код | Опис | Символ |
|-----|------|--------|
| `no` | Є світло | ✅ |
| `yes` | Відключення | ❌ |
| `maybe` | Можливе відключення | ⚠️ |
| `first` | Відключення (перші 30 хв години) | ⏰ |
| `second` | Відключення (другі 30 хв години) | ⏰ |
| `mfirst` | Можливе відключення (перші 30 хв) | ⚠️ |
| `msecond` | Можливе відключення (другі 30 хв) | ⚠️ |

## 🏗️ Як це працює

### 1. Завантаження даних

При завантаженні сторінки ДТЕК, всі дані про графіки вже вбудовані в HTML як JavaScript змінні:

```javascript
DisconSchedule.streets = {"м. Дніпро": ["вул. Конотопська", ...], ...}
DisconSchedule.fact = {"data": {"1766008800": {"GPV1.1": {...}, ...}}}
```

### 2. Парсинг JavaScript

Парсер витягує ці дані з HTML використовуючи регулярні вирази та JSON парсер.

### 3. AJAX запит для групи

Для отримання номерів будинків та відповідних груп відключень, парсер робить AJAX запит:

```python
POST /ajax/discon-schedule/
data: {
    'method': 'getHomeNum',
    'data[0][name]': 'city',
    'data[0][value]': 'м. Дніпро',
    'data[1][name]': 'street',
    'data[1][value]': 'вул. Конотопська'
}
```

### 4. Отримання графіка

Після знаходження групи (наприклад `GPV1.1`), парсер витягує графік з `DisconSchedule.fact`.

## 🔗 Структура даних на сайті

Сайт ДТЕК використовує такі структури даних:

### Streets (Вулиці)
```json
{
  "м. Дніпро": ["вул. Конотопська", "вул. Інша", ...],
  "м. Кривий Ріг": [...],
  ...
}
```

### Fact (Фактичні графіки)
```json
{
  "data": {
    "1766008800": {  // Unix timestamp
      "GPV1.1": {    // Група
        "1": "no",     // Година 1: є світло
        "2": "no",     // Година 2: є світло
        "3": "yes",    // Година 3: відключення
        ...
      }
    }
  },
  "update": "18.12.2025 20:00"
}
```

## ⚠️ Важливі примітки

1. **Оновлення даних**: Графіки оновлюються кілька разів на день. Рекомендуємо викликати парсер періодично для отримання актуальних даних.

2. **Обмеження запитів**: Будь ласка, не робіть занадто багато запитів до сайту ДТЕК. Рекомендуємо мінімум 5-10 хвилин між запитами.

3. **Зміна структури**: Якщо ДТЕК зміне структуру сайту, парсер потрібно буде оновити.

## 🛠️ Налагодження

Якщо парсер не працює, виконайте наступні кроки:

### Крок 1: Увімкніть режим діагностики

```bash
python dtek_parser.py "м. Дніпро" "вул. Конотопська" "169" --debug
```

Це покаже детальну інформацію про:
- Завантаження сторінки
- Розпізнані JavaScript дані
- AJAX запити
- Знайдені міста та вулиці

### Крок 2: Перевірте доступні міста

Можливо назва міста відрізняється на сайті:

```bash
python dtek_parser.py --list-cities --filter "Дніпро"
```

### Крок 3: Збережіть HTML для ручної перевірки

```bash
python dtek_parser.py "м. Дніпро" "вул. Конотопська" "169" --save-html debug.html --debug
```

Потім відкрийте `debug.html` і перевірте чи там є `DisconSchedule.streets`.

### Крок 4: Перевірте доступність сайту

```bash
curl -I https://www.dtek-dnem.com.ua/ua/shutdowns
```

### Типові проблеми та рішення

**Проблема**: "Місто не знайдено"
- **Рішення**: Використайте `--list-cities` для перегляду точних назв міст

**Проблема**: "DisconSchedule.streets не знайдено" або HTML містить тільки Incapsula
- **Рішення**:
  1. Переконайтесь що встановлено `cloudscraper`: `pip install cloudscraper`
  2. Спробуйте з іншого IP або через VPN
  3. Можливе тимчасове блокування, спробуйте через 10-15 хвилин
  4. Перевірте збережений HTML файл

**Проблема**: Парсер зависає
- **Рішення**: Можлива тимчасова недоступність сайту, спробуйте пізніше
