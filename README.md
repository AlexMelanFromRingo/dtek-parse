# 🤖 DTEK Discord Bot з Цитатами

Discord бот, що поєднує функції збереження цитат та перегляду графіків відключень ДТЕК з інтерактивними кнопками.

## ✨ Особливості

### 📜 Цитати
- **Збереження цитат** через контекстне меню (ПКМ по повідомленню)
- **Випадкова цитата** з історії
- **Лідерборд** найактивніших авторів
- **Підтримка зображень** в цитатах

### ⚡ DTEK Графіки
- **Інтерактивні кнопки** для вибору груп
- **Кешування на 30 хвилин** - не перевантажує сайт ДТЕК!
- **Улюблена група** - швидкий доступ
- **Пошук за адресою**
- **Автоматичний обхід Incapsula** з retry логікою

## 🚀 Встановлення

### 1. Склонувати проект

Цей бот вже готовий до використання!

### 2. Створити Discord Application

1. Перейдіть на https://discord.com/developers/applications
2. Створіть нову Application
3. В розділі "Bot" створіть бота і скопіюйте токен
4. В розділі "OAuth2" -> "URL Generator":
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: `Send Messages`, `Embed Links`, `Read Message History`, `Use Slash Commands`
5. Використайте згенерований URL для додавання бота на сервер

### 3. Налаштування

```bash
# Скопіюйте приклад .env
cp .env.example .env

# Відредагуйте .env та додайте ваш токен
nano .env
```

Вставте ваш `DISCORD_TOKEN` в файл `.env`.

### 4. Встановлення залежностей

Переконайтесь що встановлено:
- **Rust 1.70+**: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
- **curl** (для обходу Incapsula): зазвичай вже встановлено

### 5. Запуск

```bash
# Збірка та запуск
cargo run --release

# Або тільки збірка
cargo build --release
./target/release/dtek-discord-bot
```

## 💾 Система Кешування

Бот автоматично кешує дані на **30 хвилин**:

- ✅ **Перевага**: не перевантажує сайт ДТЕК
- ✅ **Швидкість**: миттєві відповіді з кешу
- ✅ **Логування**: бачите HIT/MISS/EXPIRED в логах

```
✅ Кеш HIT для групи: GPV3.2 (кешовано 5 хв тому)
❌ Кеш MISS для групи: GPV1.1
⏰ Кеш EXPIRED для групи: GPV6.2
🌐 Запит до DTEK для групи: GPV6.2
💾 Кеш SAVED для групи: GPV6.2
```

Змінити тривалість кешу можна в `.env`:
```bash
CACHE_DURATION_MINUTES=45  # 45 хвилин замість 30
```

## 🏗️ Архітектура

```
src/main.rs
├── CachedSchedule        # Структура для кешованих даних з timestamp
├── get_cached_or_fetch_schedule()  # Логіка кешування для графіків
├── get_cached_groups_list()        # Логіка кешування для списку груп
├── handle_button_interaction()     # Обробник кнопок
└── Commands
    ├── Цитати (save_quote, quote, leaderboard)
    └── DTEK (dtek_*, з кешуванням)
```

### Кеш використовує:
- `Arc<RwLock<HashMap>>` - thread-safe доступ
- `chrono::DateTime` - перевірка expiry
- Окремий кеш для кожної групи
- Спеціальний ключ `__GROUPS_LIST__` для списку груп

## 📊 База Даних

SQLite база (`quotes.db`) з двома таблицями:

```sql
-- Цитати
quotes (id, guild_id, author_name, content, attachment_url, created_at)

-- Улюблені групи користувачів
user_groups (user_id, guild_id, favorite_group)
```

- `debug` - детальна інформація
- `trace` - все

## 🐛 Troubleshooting

### "DisconSchedule not found"
- Сайт ДТЕК тимчасово недоступний або змінив формат
- Спробуйте `/dtek_очистити_кеш` (для адмінів)
- Почекайте 1-2 хвилини

### Бот не відповідає
- Перевірте логи: `RUST_LOG=debug cargo run`
- Перевірте токен в `.env`
- Переконайтесь що бот має права на сервері

### Повільні відповіді
- Перший запит завжди повільніший (запит до ДТЕК)
- Наступні запити миттєві (з кешу)
- Перевірте інтернет з'єднання
